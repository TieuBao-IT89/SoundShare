# Be Vietnam Pro

Bundled Regular (400), Medium (500), SemiBold (600) and Bold (700) from the [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/bevietnampro). These files include Vietnamese glyphs and are loaded locally by Flutter and Clerk Web; the app does not fetch fonts at runtime.
