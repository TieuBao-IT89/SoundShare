# Contributing to SoundShare

Thanks for helping improve SoundShare.

## Workflow

1. Fork the repository and create a focused branch from the current default branch.
2. Keep changes scoped and follow the feature-first structure and existing Dart style.
3. Run `dart format .`, `flutter analyze`, and `flutter test`.
4. Open a pull request with a clear summary, screenshots for UI changes, and notes about any follow-up work.

For larger changes, open an issue first so the approach can be discussed. Do not include credentials, private user data, or generated build output in commits. See the [Code of Conduct](CODE_OF_CONDUCT.md) for community expectations.
